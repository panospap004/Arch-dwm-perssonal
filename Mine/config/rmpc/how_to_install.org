this is for the development branch of 0.12.0

you will need to add cargo to path for example for fish 

#+begin_src shell
cargo install --git https://github.com/mierak/rmpc.git rmpcd
cargo install --git https://github.com/mierak/rmpc rmpc
fish_add_path ~/.cargo/bin
#+end_src

you will need 

~/.config/rmpc/
  1. config.ron will live
  2. themes/ themes will live here

~/.config/rmpcd/init.lua will live here

~/.config/systemd/user/rmpcd.service will live here

rmpcd.service
#+begin_src shell
[Unit]
Description=rmpcd companion daemon for rmpc
After=mpd.service

[Service]
ExecStart=%h/.cargo/bin/rmpcd
Restart=on-failure

[Install]
WantedBy=default.target

#+end_src

you start rmpcd with 

#+begin_src shell
rmpcd init

systemctl --user daemon-reload
systemctl --user enable --now rmpcd.service
systemctl --user status rmpcd.service
#+end_src

and then copy paste the rmpc files in the directorys and launch it
